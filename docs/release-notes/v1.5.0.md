### Upgrading

- **Windows:** exit the tray app first (right-click its tray icon, **Exit**), then install the new `PocketPossum.scr` as
  before. Your settings are kept.
- **Linux:** `sudo apt install ./pocket-possum_1.5.0_all.deb` upgrades in place; your settings are kept.

### What's new

- **Wiener dog** in **Settings > Scene > Animal**: a reddish-brown dachshund, very long and low, with short legs, floppy
  ears, a long snout and a thin wagging tail. It pants with its tongue out like the dog does.
- It brings its own cast, with the same chases, standoffs, snack stealing and family outings as the others: Frankie as the
  lead, Oscar as the troublemaker, Greta as the mother, and the puppies Pretzel, Schnitzel and Strudel. Messages use the
  right words, for example "A second wiener dog wandered in after dark!".
- The animal choices are now: possum, cat, raccoon, dog, wiener dog and lizard.

### Known limitations

- The Linux version has not been tested on multiple monitors, real GNOME/KDE/Xfce desktops, native Wayland or other
  distributions (see the 1.4.0 notes). The wiener dog itself was checked in the Windows build; the Linux build shares the
  same page and passed its automated install and render test in CI.
- The project has no open-source licence yet, so the Linux package's copyright file says all rights are reserved.
- Bandit-style troublemakers and the family appear every night; there is no setting to turn them off yet.
- The Windows `.scr` is unsigned.
