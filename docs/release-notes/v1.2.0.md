### Upgrading

Exit the tray app first (right-click its tray icon, **Exit**) so the old file isn't locked, then install the new
`PocketPossum.scr` as before (right-click, **Install**). Your settings are kept.

### What's new

**Live desktop wallpaper**
- Right-click the tray icon and tick **Live wallpaper** (or use **Settings > Startup**). Untick it to get your normal
  wallpaper back. With "Run in the tray when Windows starts" on, it returns after every login.
- The scene runs behind the desktop icons and any widgets, on every monitor, using your weather, day/night, season and
  scene settings. It is muted and takes no mouse or keyboard input, so clicks reach your desktop as normal.
- It **pauses automatically while a full-screen app or game is in front**, and resumes when you leave it.
- Works with both the classic Windows desktop layout and the newer Windows 11 24H2 layout.
- Command line: `PocketPossum.exe /b` runs it directly.

### Known limitations

- Tested on a single monitor; multiple monitors should work but are untested. A full-screen app on one monitor may pause
  the wallpaper on all of them.
- A maximized (not full-screen) window still covers the wallpaper, and the wallpaper keeps animating behind it.
- The floating clock wanders the screen and can sit under your own desktop widgets.
- The `.scr` is unsigned. Bandit and the Maple family appear every night, with no setting to turn them off yet.
- Windows only (x64).

Full details are in the [README](https://github.com/TPandaGames/possum-live-wallpaper#readme).
