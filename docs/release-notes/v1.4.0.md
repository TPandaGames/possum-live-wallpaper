## Possum Operational ScreenSaver (POSS) v1.4.0: Linux version

The scene now runs on **Linux** too, packaged as a `.deb` for Debian, Ubuntu and derivatives. The Windows app is
unchanged apart from the version number.

### Linux

```bash
sudo apt install ./pocket-possum_1.4.0_all.deb     # installs Python, GTK3 and WebKit2GTK as needed
pocket-possum --settings                            # or open "Possum Operational ScreenSaver" from your app menu
```

| Command | What it does |
|---|---|
| `pocket-possum --screensaver` | Full-screen on every monitor; any key, click, scroll or mouse movement exits |
| `pocket-possum --wallpaper` | Live desktop background on every monitor (X11 / XWayland only) |
| `pocket-possum --watch` | Idle watcher: starts the screensaver after the idle time and manages the wallpaper |
| `pocket-possum --window` | A normal window |
| `pocket-possum --settings` | Settings dialog |

Everything from the Windows version works the same: the choice of **possum, cat, raccoon, dog or lizard**, day and night,
four seasons, optional **real weather sync**, the chaotic family and burn-in protection. Settings are in
`~/.config/PocketPossum/settings.json`. Install `xprintidle` for the idle watcher. Remove it with
`sudo apt remove pocket-possum` (your settings are kept).

**Linux differences**
- No tray icon: the idle watcher runs in the background (`pocket-possum --watch`, or tick *Run the idle watcher when I log in*).
- The wallpaper and idle watcher need **X11**. Wayland desktops don't allow a window behind the desktop or app access to
  idle time; on Wayland, point your desktop's idle/lock settings at `pocket-possum --screensaver`.
- The wallpaper does not pause for full-screen apps on Linux yet.

**How it was tested:** Debian 13 (trixie) under WSL2 with a virtual X server and the Openbox window manager: install and
removal, `lintian` clean, the screensaver (idle, exit on mouse, key and click), the wallpaper window type, the idle
watcher, the settings dialog and live weather. **Not tested:** multiple monitors on Linux, real GNOME/KDE/Xfce desktops,
native Wayland, and other distributions. Please report problems on the issue tracker.

### Windows

No functional changes; upgrade only if you want the matching version number. Requirements and install steps are in the
[README](https://github.com/TPandaGames/possum-live-wallpaper#readme).

### Known limitations

- The project has no open-source licence yet, so the Linux package's copyright file says all rights are reserved.
- Bandit and the family appear every night; there is no setting to turn them off yet.
- Windows and Linux builds are tested on a single monitor.
- The Windows `.scr` is unsigned.
